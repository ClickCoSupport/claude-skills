# claude-skills

Claude Code skills used by Click Consulting Services. Each folder is one skill with its `SKILL.md` and supporting files.

This repo is cloned to `~/.claude/skills`, so Claude Code loads these skills directly.

| Skill | What it does |
|---|---|
| `blueprint` | Strategy & copy → design & UX/UI → Elementor build → launch. Includes `tools/` (favicon fetcher and projects index page). |
| `website-strategic-copy` | Direct-response website copy and page structure. |
| `ui-ux-pro-max` | Design system / tokens guidance. |
| `audit-website-prelaunch` | Pre-launch website audit. |
| `apple-design` | Apple-style interface and motion design. |
| `bencium-controlled-ux-designer` | UX direction, presented as options for the user to choose from. |
| `frontend-design` | Distinctive, non-templated visual design. |
| `no-ai-look` | Strips generic "AI-generated" styling and copy. |

## Setup on a new machine

```bash
git clone https://github.com/ClickCoSupport/claude-skills.git ~/.claude/skills
```

`synced/` and `.trash/` are managed by the Claude desktop app and are git-ignored.
